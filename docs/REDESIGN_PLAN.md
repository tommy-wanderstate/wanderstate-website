# Wander State Website Redesign Plan

> **Purpose:** Prioritized roadmap to align the website with brand attributes
> **Created:** February 6, 2026
> **Status:** Planning

---

## The Goal

Transform the site from a **product-focused wellness beverage site** into a **story-rich, emotionally resonant brand experience** that embodies:

- Grounded
- Intentional
- Exploratory
- Quietly Premium
- Supportive, not pushy
- Ritual Driven

## Phase 2: Homepage Transformation
*Estimated time: 2-3 sessions*

The homepage sets the emotional tone for everything.

### 2.1 Hero Section Rewrite
**Current:** "Functional Sparkling Teas powered by mushrooms and pure maple water."
**Goal:** Emotional, grounded, inviting

- [ ] Rewrite hero copy to lead with emotion
- [ ] Add "ritual moment" language
- [ ] Consider: "A sparkling tea for the moments that matter. Crafted with patience. Rooted in nature."

### 2.2 Product Section → Ritual Moments
**Current:** Features dayparts but doesn't celebrate them as rituals

- [ ] Reframe each product as a moment/ritual, not just a flavor
- [ ] Add micro-copy: "Your morning clarity ritual" / "Your evening unwind"
- [ ] Consider time-of-day visual cues

### 2.3 Replace Placeholder Sections
- [ ] "Wander with Purpose" section — add real outdoor imagery
- [ ] Community section — add real community/gathering imagery
- [ ] Add texture and warmth throughout

### 2.4 Add "Our Story" Teaser
- [ ] Brief founder intro on homepage
- [ ] Link to full About/Partners page
- [ ] Human photo if available

### 2.5 Sourcing Story Teaser
- [ ] Add "Where It Comes From" section
- [ ] Brief callouts: "Mushrooms grown in San Diego. Maple tapped in Vermont."
